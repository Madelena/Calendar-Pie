# Bundled fonts

- [Inter](https://github.com/rsms/inter), copyright 2016 The Inter Project Authors. [SIL Open Font License 1.1](Inter-OFL.txt).
- [Open Sans](https://github.com/googlefonts/opensans), copyright 2020 The Open Sans Project Authors. [SIL Open Font License 1.1](Open-Sans-OFL.txt).

Unmodified variable fonts are bundled through the corresponding Fontsource packages and served locally. Only the character subsets needed by the browser are requested. These notices and license files are copied into `dist/licenses/` by the build.

Custom fonts are supplied by the user and stored only in the current browser.
